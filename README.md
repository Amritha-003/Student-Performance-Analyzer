# Student Performance Analyzer

A beginner-friendly Python command-line project that reads student marks from a CSV file and generates a simple performance report.

## Features

- Reads student names and marks from `sample_data.csv`
- Calculates total marks and percentage
- Assigns a grade using example thresholds
- Calculates the class average
- Identifies the top performer

## Requirements

Python 3.8 or newer. The project uses only Python's standard library, so no extra packages are needed.

## Run the project

1. Download or clone this repository.
2. Keep `student_analyzer.py` and `sample_data.csv` in the same folder.
3. Run:

   ```bash
   python student_analyzer.py
   ```

Each of the three sample subjects is marked out of 100. You can edit the CSV file to try your own fictional/example data; keep the three subject columns named `subject1`, `subject2`, and `subject3`.

## Example grading scale

- 90–100%: A
- 80–89.9%: B
- 70–79.9%: C
- 60–69.9%: D
- Below 60%: Needs Improvement

These thresholds are examples only; change them to match your institution's grading policy.

## Learning goals

Practice reading CSV data, using functions, loops, conditionals, calculations, and formatted output in Python.

## Privacy

Use fictional or anonymized sample data. Do not upload classmates' private marks or personal information without permission.
